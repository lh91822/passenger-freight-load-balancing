# passenger-freight-load-balancing

客货同载车辆载荷自动均衡优化算法。

Load balancing optimization for passenger-freight co-transportation rolling stock: given a set of unit load devices and an 8-car formation, compute a loading plan that satisfies centre-of-gravity and wheel-load safety constraints within the on-board time limit.
